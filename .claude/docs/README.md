2. [backend.md](backend.md) — Django/DRF: settings, model, rotas, regras de validação.
3. [frontend.md](frontend.md) — React (CRA): rotas, páginas, componentes, fluxo de auth.
4. [known-issues.md](known-issues.md) — bugs conhecidos e pontos de atenção.
